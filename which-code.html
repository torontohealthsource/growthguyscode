These codes cannot be stacked, and that is measurable

Growth Guys' discount codes are configured as individual-use. When one code is already attached to a cart, the store silently refuses to attach a second — the request returns without an error message, and the discount line simply does not change. We found this while building the daily test: an earlier version of our checker did not clear the previous coupon between tests, and every code after the first one appeared to be dead. It was not. The cart was rejecting the second coupon because the first was still on it. So there is no combination of codes that beats 10%, and any page telling you to stack two Growth Guys codes for 20% is describing something the store will not do.
