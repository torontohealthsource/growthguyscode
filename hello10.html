Coupon code, promo code, discount code — same field, same code

At growthguys.com these are three names for one thing. The checkout has a single field, and the same string works in it regardless of which word brought you here. We mention it because the three phrasings return different search results, and a buyer who searched 'coupon code' can end up on a page listing something different from the buyer who searched 'discount code' — for the same store, on the same day. Every code on this site is tested in that one field, and the figures below are what the field actually returned.

No product exclusions, tested across the price range

The discount is not limited to cheap items or to a single category. We cross-tested every code against a spread of the catalogue — from a $5.00 CAD consumable up to the $430.00 CAD HGH kit — and each returned exactly 10% at every price point, including the HGH kits, which are the items most often excluded by vendors running percentage promotions. One cart quirk worth knowing: products sold in multiple variants need a variant chosen before they will enter the cart at all. If you apply a code to what looks like an empty cart, you will see no discount, and the code is not the reason.

These codes cannot be stacked, and that is measurable

Growth Guys' discount codes are configured as individual-use. When one code is already attached to a cart, the store silently refuses to attach a second — the request returns without an error message, and the discount line simply does not change. We found this while building the daily test: an earlier version of our checker did not clear the previous coupon between tests, and every code after the first one appeared to be dead. It was not. The cart was rejecting the second coupon because the first was still on it. So there is no combination of codes that beats 10%, and any page telling you to stack two Growth Guys codes for 20% is describing something the store will not do.
